2026 東京・日光・成田餐廳實拍攻略

開啟方式：
1. 解壓縮完整資料夾。
2. 使用 Chrome 或 Edge 開啟 index.html。
3. 首頁包含 32 間餐廳；每間餐廳都有獨立攻略頁。
4. 進入餐廳頁後，可在「必點餐點與點法」查看每一道推薦餐點的圖片與來源。

字型：優先使用 Windows 的標楷體（DFKai-SB／BiauKai）。
版面：已針對桌機、平板與手機設計；手機窄螢幕會改成圖片在上、文字在下。
資料：restaurants-data.json 保留每間店的推薦餐點、圖片模式、查詢詞與來源網址。
照片：
- 一蘭新宿歌舞伎町店與野口鮮魚店的 8 道推薦餐點，已逐項配對照片、封裝於 assets/dish-photos/，並保留原始來源連結。
- 其他餐廳的第一推薦保留原有店家／餐廳資訊來源照片。
- 其他非第一推薦餐點，會依餐點名稱載入 Wikimedia Commons 授權參考照片。
- 若外部圖片或參考照片載入失敗，會自動顯示內建料理示意圖，不會出現破圖。

注意：上述兩間餐廳的 8 張推薦餐點照片可離線顯示；其他外部照片與 Wikimedia Commons 參考照片仍需連網。所有照片用於行前辨識，實際菜色、擺盤與供應仍以到店當日為準。
